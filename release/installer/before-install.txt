Nox — русскоязычный голосовой ассистент и помощник трейдера для Windows 10/11 (x64).

ЧТО СДЕЛАЕТ УСТАНОВЩИК
• Распакует программу в C:\jarvis-lab и C:\jarvis-voice (пути менять нельзя — так устроена программа;
  кириллица в пути ломает распознавание речи).
• Уже внутри установщика: окно и голосовой движок Nox, распознавание речи Vosk (русский),
  модели GLiNER и эмбеддингов, голос Silero, модели ударений RUAccent.
• Скачает из интернета (нужен интернет, 10–30 минут):
  – Python 3.11 (python.org), если его нет;
  – библиотеки Python (~1 ГБ, PyPI и pytorch.org);
  – Visual C++ Runtime и WebView2, если их нет;
  – по желанию: Ollama + модель qwen2.5:3b (~3 ГБ) — бесплатный локальный «мозг»;
  – по желанию: Яндекс.Браузер — в нём открывается Т-Терминал, откуда Nox читает новости и календарь;
  – по желанию, только с видеокартой NVIDIA: голос Джарвиса — клон по образцу (F5-TTS и/или XTTS v2):
    torch для видеокарты ~3 ГБ + модели 1,4–1,9 ГБ. Качается кусками с проверкой, обрыв не страшен.
• Голоса Silero (aidar, eugene, baya, kseniya, xenia) уже внутри и работают на любом компьютере.
• Создаст ярлык «Nox» на рабочем столе и в меню Пуск.

ПОСЛЕ УСТАНОВКИ (один раз, вручную)
• При первом запуске откроется окно «Профиль»: ваше имя и ключи (T-Invest, APIMIRA, BLS, BEA и др.).
  Ключи хранятся только на вашем компьютере.
• В окне Яндекс.Браузера Nox (ярлык «Nox — окно Т-Терминала») войдите в Т-Банк и откройте терминал
  с панелями новостей и календаря.

ВАЖНО ПРО СДЕЛКИ
Nox умеет сам нажимать «Купить/Продать» в Т-Терминале и CScalp. По умолчанию исполнение ВЫКЛЮЧЕНО
(Настройки → «Т-Терминал», там же лимиты). Включая его, вы берёте риск на себя: программа
распространяется «как есть», без гарантий, и не является инвестиционной рекомендацией.
