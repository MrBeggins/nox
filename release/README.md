# Nox — голосовой помощник трейдера (Windows 10/11)

Nox — русскоязычный голосовой ассистент: слушает голос и горячую клавишу, отвечает облачным
или локальным «мозгом», читает новости и календарь из Т-Терминала, следит за событиями
(«наблюдатели»: решения ЦБ/ФРС, Минфин, корпоративные новости) и озвучивает их.
По желанию пользователя умеет сам нажимать заявки в Т-Терминале и CScalp (по умолчанию выключено).

## Установка (для пользователей)

1. Скачайте `Nox-Setup-<версия>.exe` (раздел Releases на GitHub или торрент).
2. Запустите. Права администратора не нужны (Windows спросит их только для Visual C++ Runtime, если его нет).
   Установщик не подписан цифровой подписью, поэтому Windows может показать «Система Windows защитила ваш компьютер» —
   нажмите «Подробнее» → «Выполнить в любом случае». Целостность файла можно сверить с `Nox-Setup-<версия>.exe.sha256`.
3. Мастер распакует программу в `C:\jarvis-lab` и `C:\jarvis-voice` и откроет окно донастройки:
   Python 3.11, библиотеки (~1 ГБ), по желанию Ollama + модель и Яндекс.Браузер. Нужен интернет, 10–30 минут.
4. Запуск — ярлык **Nox** на рабочем столе. При первом запуске откроется окно «Профиль»:
   имя и ключи (T-Invest, APIMIRA, BLS, BEA, FMP…). Ключи хранятся только у вас — `%APPDATA%\com.priler.jarvis\app.db`.
5. Ярлык **«Nox — окно Т-Терминала»**: один раз войти в Т-Банк, открыть терминал с панелями новостей и календаря.

Что-то не встало (обрыв интернета и т. п.) — меню Пуск → **Nox — починить установку**. Журнал: `C:\jarvis-voice\install.log`.
Удаление — «Параметры → Приложения» или меню Пуск → «Удалить Nox» (личные файлы и настройки остаются).

**Требования:** Windows 10 1809+ / 11, x64, микрофон, ~6 ГБ на диске C: (с Ollama — ~9 ГБ). Видеокарта не нужна.

> ⚠️ **Сделки.** Исполнение заявок выключено по умолчанию (Настройки → «Т-Терминал», там же лимиты).
> Включая его, вы берёте риск на себя. Программа распространяется «как есть», без гарантий, и не даёт инвестиционных рекомендаций.

## Состав этой папки

| Папка / файл | Что это |
|---|---|
| `dist\Nox-Setup-<версия>.exe` (+ `.sha256`) | готовый установщик — его и раздавать |
| `source\` | чистые исходники (Rust + Svelte + Python) без ключей и личных файлов — можно выкладывать на GitHub |
| `installer\` | сценарий установщика: `Nox.iss` (Inno Setup), `setup-nox.ps1` (донастройка), `stop-nox.ps1`, `requirements-nox.txt`, `app.db.template` (стартовые настройки без ключей) |
| `payload\` | то, что упаковано в установщик (промежуточная папка сборки, раздавать не нужно) |
| `build.py`, `Собрать-установщик.cmd` | пересборка всего одной командой |
| `sync_github.py` | перенос изменений из рабочих папок в git-копию `C:\nox` с проверкой на ключи (`--apply` — записать) |

Что внутри установщика: `jarvis-app.exe` (голосовой движок), `jarvis-gui.exe` (окно), DLL, распознавание речи
Vosk (русская модель), GLiNER и модели эмбеддингов, Python-службы, голос Silero `v4_ru`, модели ударений RUAccent.
Скачивается при установке: Python 3.11, библиотеки PyPI (torch CPU и др.), при необходимости VC++ Runtime и WebView2,
по желанию Ollama + `qwen2.5:3b` и Яндекс.Браузер.

### Голоса

- **Silero** — 5 голосов (aidar, eugene, baya, kseniya, xenia), уже внутри установщика, работают на любом ПК (CPU).
- **Голос Джарвиса — клон по образцу** `ref_jarvis_og.wav` (галочки появляются только при видеокарте NVIDIA):
  - **F5-TTS** — модель `Misha24-10/F5-TTS_RUSSIAN` (~1,4 ГБ) + вокодер vocos;
  - **XTTS v2** — модель `coqui/XTTS-v2` (~1,9 ГБ) в своём окружении `.venv-xtts`, после установки проходит самопроверку.

  Обоим нужен torch для видеокарты (CUDA 12.8, ~3 ГБ, ставится один раз). Всё качается при установке кусками
  с проверкой SHA-256 (`installer\nox_fetch.py`): обрыв не страшен, «Починить установку» продолжит с места.
  В установщик модели не вшиты: иначе он перерос бы лимит GitHub в 2 ГБ на файл.
- Переключение — Настройки → «Голос». По умолчанию всегда Silero (быстрый).
- Модели клонов — под некоммерческими лицензиями своих авторов (XTTS — Coqui Public Model License).

## Пересборка установщика (для автора)

Нужно: Inno Setup 6 (`winget install JRSoftware.InnoSetup`), Python 3.11, рабочие папки `C:\jarvis-lab`
(собранный `target\release`) и `C:\jarvis-voice` (с `.venv` — оттуда берутся модели RUAccent), git-копия `C:\nox`
(из неё берётся список файлов кода).

```
cd C:\jarvis-lab\frontend && npx vite build
cd C:\jarvis-lab && cargo build --release -p jarvis-app -p jarvis-gui
py -3.11 C:\jarvis-lab\post_build.py
py -3.11 C:\nox-release\build.py
```

`build.py` обновит `source\` и `payload\`, проверит их на ключи/токены/личные файлы (при находке — остановится)
и соберёт `dist\Nox-Setup-<ГГГГ.ММ.ДД>.exe`. Только проверить без компиляции: `build.py --no-compile`.

## Сборка из исходников (для разработчиков)

Rust (MSVC), Node.js LTS, Python 3.11, Visual Studio Build Tools (C++). Пути только ASCII: `C:\jarvis-lab`, `C:\jarvis-voice`.
Скопируйте `source\jarvis-lab` → `C:\jarvis-lab`, `source\jarvis-voice` → `C:\jarvis-voice`, затем:

```
cd C:\jarvis-lab\frontend && npm install && npx vite build
cd C:\jarvis-lab && cargo build --release -p jarvis-app -p jarvis-gui && py -3.11 post_build.py
```

Модели (Vosk, GLiNER, эмбеддинги) кладутся в `C:\jarvis-lab\resources\models` и `resources\vosk` — их проще взять из установщика.
Службы и порты: `jarvis-app` :9712, TTS :8123, `invest_reader` :8124, `terminal_reader` :8126, `magellan_reader` :8127,
`bls_reader` :8128, `bea_reader` :8129, сторож `nox_watchdog` :8130, `sys_monitor` :8132, `nox_notes` :8133, Ollama :11434.
