# Jarvis — полный хендовер (передача на другой ПК / новую сессию)

Этот файл — самодостаточная сводка всего, что сделано, где что лежит, как запускать и что осталось.
Читается как «введи нового человека (или новую сессию Claude Code) в проект с нуля».

---

## 0. Суть проекта
Берём офлайн-ассистента **Priler/jarvis** (Rust + Tauri v2 + Svelte, wake-word + Vosk STT + команды)
и достраиваем то, чего в нём нет: **разговорный ИИ-мозг (Claude), голос, зрение экрана, GUI**.
Философия пользователя: по возможности **через подписку Claude, а не API-ключ**; голос — локально/бесплатно.

## 2. Машина и ГЛАВНОЕ ОГРАНИЧЕНИЕ
- Эта сессия Claude Code выполняется на **ноутбуке `DESKTOP-M43R9J2` (Intel UHD, без NVIDIA)**. Пользователь подключается к ней удалённо.
- **Локальное клонирование голоса на GPU отсюда невозможно** — нужен ПК с **RTX 5050**. Чтобы делать голос на GPU, надо запустить **Claude Code на самом этом ПК** (отдельная сессия) и перенести туда `jarvis-lab` (этот архив).

## 3. Что уже сделано (работает)
- **Тулчейн:** Rust 1.98.1, Node 24.19.0, VS C++ Build Tools + Windows SDK, WebView2. Python 3.14.
- **Удалены игры:** Caliber, Sniper Ghost Warrior 2. (SIGame — осталось подтвердить удаление в Steam вручную.)
- **База собрана:** `jarvis-app` (фоновый ассистент, трей) и `jarvis-gui` (Tauri-конфигуратор).
- **Мозг (Claude через подписку):** `crates/jarvis-core/src/brain.rs`. Если локальная команда не распознана → зовём `claude -p "<текст>"` (подписка, НЕ API-ключ) → ответ. Хук в `crates/jarvis-app/src/app.rs` (ветка "no local command matched"). Событие `IpcEvent::AssistantReply`.
- **Голос (TTS, временный):** `crates/jarvis-core/src/tts.rs` + встроенный `speak.ps1`. Windows WinRT-голос **Pavel** (мужской, ru). Озвучивает ответ мозга. Темп через `JARVIS_TTS_RATE` (нравится **1.3**). ВАЖНО: парсинг темпа — через InvariantCulture (точка), иначе на ru-локали игнорируется.
- **GUI (Tauri v2 + Svelte):** окно-конфигуратор. Правки по просьбе пользователя: убран футер и кнопка «КОМАНДЫ» (и Telegram-ссылки), запуск **без консоли** (release-сборка + `windows_subsystem`), кнопка «ЗАПУСТИТЬ» стартует ассистент без консоли (`CREATE_NO_WINDOW` в `tauri_commands/sys.rs`).
- **Реактор (ArcReactor.svelte):** финальный вид — **полностью бирюзовый** (`arc-custom`, `--arc-color 47,230,230`), высокий контраст, дуги крутятся (mains 3s / ghosts 5s), две внешние дуги оставлены **статичными** намеренно.
- **Иконка/логотип/ярлык:** это **скруглённый скрин центра реактора** (`resources/icons/icon.ico` + 32/128/256 png + `frontend/public/media/128x128.png`). Генератор: во временной папке был `gen_icon2.ps1` (обрезка `win_full.png` → скругление). Ярлык на рабочем столе — **`Jarvis.lnk`**.
- **Зрение экрана (готово, облачное):** `crates/jarvis-core/src/vision.rs` + встроенный `capture.ps1`. Скриншот → `claude -p "<промпт> <путь>" --allowedTools Read --model haiku` → описание по-русски. Цикл в `jarvis-app` `main.rs` (env `JARVIS_VISION`, интервал `JARVIS_VISION_INTERVAL` def 3). Описание шлётся как `AssistantReply "👁 ..."` и показывается в GUI (бирюзовая панель на главном экране; `ipc.ts` стор `lastAssistantReply`, реэкспорт в `stores.ts`, вывод в `routes/index.svelte`). GUI-коннект сделан устойчивым (`App.svelte` `enableIpc()`, reconnect в `ipc.ts`). **Зрение → Haiku, мозг → Sonnet** (правка в vision.rs; на момент хендовера пересборка jarvis-app с этой правкой НЕ доведена — см. §7).

## 4. Как запускать
- Двойной клик по **`Jarvis.lnk`** на рабочем столе → окно (release, без консоли) → кнопка «ЗАПУСТИТЬ» поднимает ассистента.
- Или `run-jarvis.cmd` в `jarvis-lab` — запускает ассистента напрямую (debug, с логами).
- Скажи «джарвис» + вопрос: локальные команды — сразу; разговорное — уходит в Claude, ответ озвучивается Pavel.

## 5. Переменные окружения (тонкая настройка, без пересборки)
| Переменная | Назначение | Значение |
|---|---|---|
| `JARVIS_BRAIN` | вкл/выкл мозг | по умолч. вкл; `0` — выкл |
| `JARVIS_BRAIN_MODEL` | модель мозга | по умолч. (Sonnet) |
| `JARVIS_TTS` / `JARVIS_TTS_VOICE` / `JARVIS_TTS_RATE` | озвучка / голос / темп | вкл / `Pavel` / `1.3` |
| `JARVIS_VISION` | авто-зрение | **сейчас `0` (выключено, чтобы не тратить токены)** |
| `JARVIS_VISION_INTERVAL` | интервал зрения, сек | `3` |
| `JARVIS_VISION_MODEL` | модель зрения | `haiku` |

## 6. Важные ограничения / нюансы (честно)
- **Кириллица в пути ломает Vosk (libvosk/Kaldi)** → всё держим в ASCII-пути (`jarvis-lab`).
- **VPN Happ (TUN) должен быть включён** для мозга и зрения: из РФ `api.anthropic.com` иначе даёт 403. `claude login` уже сделан на реальной машине пользователя.
- **`claude` CLI** ставится через `npm i -g @anthropic-ai/claude-code` (нужен `--allow-scripts`, чтобы докачался бинарник). Лежит в `%APPDATA%\npm`.
- **Зрение**: каждый вызов Claude-vision ~несколько секунд (с Haiku быстрее), тратит токены подписки; скриншоты уходят в облако (отключаемо через `JARVIS_VISION=0`).
- Клонирование голоса из фильма как у автора видео = **ElevenLabs** (облако, платно, API-ключ). Мы выбрали путь **локального клона на GPU** (бесплатно/приватно) — но нужен ПК с RTX 5050.

## 7. Что осталось / СЛЕДУЮЩИЕ ШАГИ
1. **ГОЛОС — локальный клон** (главное): на ПК с **RTX 5050**. Сэмплы для клонирования уже есть — заготовленные фразы: `resources/sound/voices/jarvis-howdy` (18 wav), `jarvis-og` (13 wav). Кандидаты моделей: **GPT-SoVITS / F5-TTS / XTTS-v2** (клон из коротких сэмплов, русский). Нюанс: RTX 50-й серии → нужен свежий CUDA/PyTorch (cu128). Итог: заменить/дополнить Pavel в `tts.rs` вызовом локального TTS-сервера для ответов мозга.
2. **Довести пересборку `jarvis-app` с правкой «зрение→Haiku»** (последняя сборка упала с кодом 4 — скорее всего exe был занят запущенным процессом; надо закрыть Jarvis и пересобрать `cargo build -p jarvis-app`, затем скопировать exe в `target/release`).
3. По желанию: переключатель зрения в настройках GUI (сейчас через env), ускорение мозга, игровой модуль (мгновенные команды как в видео), удалить SIGame.

## 8. Как поднять проект на новом ПК (кратко)
1. Установить: Rust (rustup), Node LTS, VS C++ Build Tools (workload VCTools), (WebView2 обычно есть). `npm i -g @anthropic-ai/claude-code`, затем `claude login` (VPN вкл).
2. Распаковать `jarvis-lab` в **ASCII-путь** (напр. `C:\Users\<user>\jarvis-lab`).
3. `cd frontend && npm install && npx vite build` (именно `npx vite build`, не `npm run build` — там падает svelte-check на .routify).
4. `cargo build --release -p jarvis-gui` и `cargo build -p jarvis-app`, затем `python post_build.py` (копирует DLL/ресурсы в target). Для release ещё скопировать `jarvis-app.exe` в `target/release`.
5. Запуск: `target/release/jarvis-gui.exe` (или пересоздать ярлык).
