# Jarvis + Claude-мозг — экспериментальная копия

Это копия проекта **Priler/jarvis** с добавленным «мозгом» на Claude, работающим
**через твою подписку** (локальный `claude` CLI), а не через API-ключ.

Расположение копии: `C:\Users\tyako\jarvis-lab` (специально ASCII-путь — см. «Важно» ниже).
Оригинал остался в `C:\Users\tyako\Documents\виджет\джарвис`.

---

## Что уже сделано (автоматически)

- Установлен тулчейн: **Rust 1.98.1**, **Node 24.19.0**, **VS C++ Build Tools + Windows SDK** (WebView2 уже был).
- Собран базовый Jarvis (`jarvis-app.exe`) — оригинал и копия.
- В копию добавлен модуль-мозг:
  - `crates/jarvis-core/src/brain.rs` — вызывает `claude -p` (подписка), с таймаутом и настройками через env.
  - Новое IPC-событие `assistant_reply` (`crates/jarvis-core/src/ipc/events.rs`).
  - Хук в `crates/jarvis-app/src/app.rs`: если локальная команда не распознана → вопрос уходит Claude → ответ шлётся в интерфейс.
- Связка проверена end-to-end (текстовая команда → мозг → ответ доставлен).

## ЕДИНСТВЕННЫЙ ручной шаг: войти в подписку один раз

Свежий `claude` CLI не наследует авторизацию десктопного приложения. Пока не войдёшь —
мозг отвечает «Not logged in» и Jarvis просто говорит «команда не найдена».

Открой обычный терминал (PowerShell) и выполни:

```
claude login
```

Откроется браузер, подтвердишь вход в свой аккаунт. Проверить:

```
claude -p "скажи одно слово: работает"
```

Если ответил — всё, мозг активен. **Код менять не нужно.**

## Как запускать

Дабл-кликом по `run-jarvis.cmd` в этой папке (или из терминала). Джарвис поднимет
микрофон, wake-word и IPC-сервер `ws://127.0.0.1:9712`.

- Голосом: скажи **«джарвис»**, затем фразу. Локальные команды (открой браузер, громкость,
  погода, игровой режим/Steam и т.п.) выполнятся как раньше; всё «разговорное» уйдёт Claude.
- Без микрофона можно слать текст по IPC (см. ниже).

### Быстрый тест мозга без микрофона

При запущенном Jarvis, из папки со скриптом:
```
node "<scratchpad>\test_client.mjs" "придумай короткий девиз для проекта"
```
(путь к `test_client.mjs` — во временной папке сессии; можешь скопировать его сюда).
Клиент отправит текст и покажет событие `assistant_reply` с ответом Claude.

## Настройка мозга (переменные окружения, без пересборки)

| Переменная | Назначение | По умолчанию |
|---|---|---|
| `JARVIS_BRAIN` | `0/false/off/no` — выключить мозг | включён |
| `JARVIS_CLAUDE_BIN` | путь к `claude` | автоопределение (`%APPDATA%\npm\claude.cmd`) |
| `JARVIS_BRAIN_MODEL` | модель для `--model` | по умолчанию CLI |
| `JARVIS_BRAIN_SYSTEM` | системный промпт | «Ты — Джарвис…, кратко, по-русски» |
| `JARVIS_BRAIN_TIMEOUT` | таймаут ответа, сек | 60 |

Для скорости голосового ответа стоит попробовать быструю модель:
`set JARVIS_BRAIN_MODEL=claude-haiku-4-5-20251001`.

## Важно / ограничения (честно)

1. **Кириллица в пути ломает Vosk.** libvosk (Kaldi) на Windows не открывает файлы по
   Unicode-пути. Поэтому копия лежит в ASCII-папке `C:\Users\tyako\jarvis-lab` и запускается.
   Оригинал в `…\виджет\джарвис` **не стартует** из-за кириллицы. Его можно запустить через
   уже созданный junction: `C:\jarvis_ascii\jarvis-app.exe`.
2. **Пока нет TTS.** Ответ Claude приходит как событие/текст в интерфейс, но вслух не
   произносится (в этой версии проекта общего синтеза речи нет). Это следующий шаг.
3. **GUI (Tauri-конфигуратор) не собран.** Ассистент работает как фоновый процесс + IPC.
   Сборку графического окна можно добавить отдельно.
4. **Задержка.** Каждый вопрос поднимает `claude` заново (~1–3 сек старта + генерация).
   Для меньшей задержки позже можно перейти на постоянную сессию Claude Agent SDK.

## Идеи для дальнейших экспериментов
- Озвучка ответов (TTS) — подключить движок и проигрывать ответ мозга.
- Постоянная сессия Claude (Agent SDK) вместо разового `claude -p` — быстрее.
- Дать мозгу доступ к контексту/командам (function-calling), чтобы он сам запускал действия.
- Сборка и доработка GUI (`crates/jarvis-gui`) с показом диалога.
