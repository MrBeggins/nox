Установка Nox с нуля

Пошаговая инструкция для нового компьютера: что скачать, как настроить и запустить. Для Windows 10/11 x64.

Граница безопасности. Nox только читает и готовит: портфель, котировки, стакан, новости, алерты, открытие нужного стакана по сценарию. Кнопку «Купить / Продать / Подтвердить» жмёшь только ты. Сделки и переводы ассистент не исполняет.

С чего начать: два пути

Есть автоматический установщик — рекомендуется. Ручной путь ниже нужен, только если хочешь ставить всё сам.

Путь A — автоматический («как игра из Steam»)

  • Скопируй папку установщика nox-installer на новый компьютер (с флешки/облака).
  • Двойной клик по Установить-Nox.bat → согласись на права администратора.
  • Он сам поставит ПО, создаст окружение, скачает модели, настроит и сделает ярлык «Nox» на рабочем столе.

Путь B — вручную

Шаги 1–7 ниже. Качаешь исходники, ставишь ПО и модели, собираешь, запускаешь.

Проект в приватном репозитории github.com/MrBeggins/nox (нужен твой вход в GitHub). Там же лежит папка installer/ и полный README.md.
1

Установить системное ПО

Проще всего через winget в PowerShell (или скачать по ссылкам из таблицы ресурсов ниже).

winget install Git.Git winget install Rustlang.Rustup winget install OpenJS.NodeJS.LTS winget install Python.Python.3.11 winget install Ollama.Ollama winget install Gyan.FFmpeg winget install Yandex.Browser

Плюс Visual Studio 2022 Build Tools с компонентом «Desktop development with C++» (нужно для сборки). После Rust — rustup default stable-msvc.

2

Разложить код по ASCII-путям

Важно: пути захардкожены и Vosk ломается на кириллице — папки должны лежать именно здесь: C:\jarvis-lab и C:\jarvis-voice.
git clone <ссылка-на-репозиторий> C:\nox-src robocopy C:\nox-src\jarvis-lab C:\jarvis-lab /E robocopy C:\nox-src\jarvis-voice C:\jarvis-voice /E
3

Python-окружение

cd C:\jarvis-voice py -3.11 -m venv .venv .\.venv\Scripts\python -m pip install --upgrade pip rem GPU (видеокарта NVIDIA): .\.venv\Scripts\python -m pip install torch torchaudio --index-url https://download.pytorch.org/whl/cu128 rem ноутбук без видеокарты — CPU: rem .\.venv\Scripts\python -m pip install torch torchaudio --index-url https://download.pytorch.org/whl/cpu .\.venv\Scripts\python -m pip install -r requirements.txt .\.venv\Scripts\python -m playwright install chromium

Проверка GPU: python -c "import torch; print(torch.cuda.is_available())" → True.

4

Скачать модели

В репозиторий не входят (большие). Разложить строго по путям — см. таблицу «Модели» ниже. Коротко:

  • Распознавание речи (Vosk): vosk-model-small-ru-0.22 → C:\jarvis-lab\resources\vosk\
  • Голос (F5-TTS, если есть GPU): model_last_inference.safetensors + vocab.txt → C:\jarvis-voice\models\ru\
  • Голос на CPU (Silero): скачается сам при первом запуске.
  • GLiNER (извлечение параметров): model_int8.onnx → переименовать в model.onnx → …\resources\models\gliner_multi-v2.1\onnx\
  • Эмбеддинги (интент): all-MiniLM-L6-v2 и paraphrase-multilingual → C:\jarvis-lab\resources\models\

Эмбеддинги и GLiNER уже лежат в папке установщика (models\), качать не нужно, если ставишь Путём A.

5

Мозг (Ollama) и сборка

ollama pull qwen2.5:3b setx OLLAMA_KEEP_ALIVE -1 cd C:\jarvis-lab\frontend npm install node node_modules/esbuild/install.js npx vite build cd C:\jarvis-lab cargo build --release -p jarvis-gui cargo build --release -p jarvis-app py -3.11 post_build.py

При Пути A сборка не нужна — в установщике готовые jarvis-app.exe / jarvis-gui.exe.

7

Запуск

powershell -ExecutionPolicy Bypass -File C:\jarvis-lab\start-jarvis.ps1

Или ярлык «Nox» на рабочем столе (создаёт установщик). Поднимаются все службы, сторож (watchdog) перезапускает упавшее. Для чтения терминала открой в окне Яндекса tbank.ru/terminal и войди один раз.

Частые грабли

  • Ключ «не видит» — у файла двойное расширение (bls_key.txt.txt) из-за скрытых расширений Windows. Включи «Вид → Расширения имён файлов» и переименуй в bls_key.txt.
  • Настройки слетают в дефолт — в app.db попал BOM. Править только в UTF-8 без BOM.
  • Vosk не грузится / тишина — путь с кириллицей. Папки должны быть в C:\jarvis-lab / C:\jarvis-voice.
  • Голос Павел вместо основного — F5/Silero-сервер (8123) ещё грузится; после прогрева идёт основной.
  • Claude «Not logged in» / 403 из РФ — нужен claude login и включённый VPN.
  • Правки ядра не применились — пересобери jarvis-app (не только GUI).
