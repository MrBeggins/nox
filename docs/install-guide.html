Nox — установка

Голосовой помощник трейдера для Windows 10/11. Установщик ставит всё сам.

Скачать Nox-Setup.exe

Раздел Releases на GitHub. Рядом — файл .sha256 для проверки целостности.

Шаги

  1. Запустите Nox-Setup-<версия>.exe. Права администратора не нужны. Если Windows покажет «Система Windows защитила ваш компьютер» — «Подробнее» → «Выполнить в любом случае» (установщик без цифровой подписи).
  2. Выберите галочки: ярлык, локальный мозг Ollama (~3 ГБ), Яндекс.Браузер, голос-клон Джарвиса (только NVIDIA).
  3. Подождите 10–30 минут: докачиваются Python 3.11 и библиотеки (~1 ГБ), при необходимости VC++ Runtime и WebView2.
  4. Запустите ярлык Nox. В окне «Профиль» укажите имя и ключи (T-Invest, APIMIRA, BLS, BEA…) — они хранятся только у вас.
  5. Ярлык «Nox — окно Т-Терминала»: войдите в Т-Банк и откройте терминал с новостями и календарём.

Если что-то не так

  • Меню Пуск → «Nox — починить установку»: докачает недостающее с места обрыва.
  • Журнал установки: C:\jarvis-voice\install.log.
  • Программа ставится строго в C:\jarvis-lab и C:\jarvis-voice — так устроены пути внутри.

Сделки

Nox умеет сам выставлять заявки в Т-Терминале и CScalp, но по умолчанию исполнение выключено (Настройки → «Т-Терминал», там же лимиты). Включая его, вы берёте риск на себя. Программа «как есть», без гарантий.
