# Nox — голосовой помощник трейдера для Windows

Nox (бывший «Джарвис») — русскоязычный голосовой ассистент для Windows 10/11. Слушает голос и горячую
клавишу, отвечает облачным или локальным «мозгом», читает новости и календарь из Т-Терминала, следит за
событиями и озвучивает их, а по включённым пользователем сценариям умеет сам выставлять заявки.

Форк [Priler/jarvis](https://github.com/Priler/jarvis) (Rust + Tauri + Svelte), расширенный Python-службами.

**➜ [Скачать установщик](https://github.com/MrBeggins/nox/releases/latest)** — `Nox-Setup-<версия>.exe`, ставит всё сам.

## Возможности

**Голос и разговор**
- Слово пробуждения «нокс» (Vosk, офлайн) или горячая клавиша / боковая кнопка мыши; ввод текстом на «Пульсе».
- Мозг: облачный по ключу (APIMIRA, OpenAI-совместимый) или локальный Ollama (`qwen2.5:3b`, бесплатно) — страница «Мозг».
- «Память»: правила общения и факты о пользователе («запомни правило…», «что ты обо мне знаешь»).
- Грамотная русская речь: голос Silero (5 дикторов), ударения RUAccent, падежи чисел (pymorphy3).
  На видеокарте NVIDIA — по желанию голос-клон Джарвиса (F5-TTS или XTTS v2).
- Помощник: монитор нагрузки ПК, заметки и напоминания, «открой <программу/сайт>», «что на экране?» (зрение по запросу).

**Рынок**
- Лента новостей Trading Tools и Stocksi (кто первый), календарь MindStocks — прямо из окна Т-Терминала.
- Фильтр ленты по тикерам/фразам/источникам, список «Не читать», смысловой фильтр повторов (Qwen через Ollama).
- **Наблюдатели**: ждут нужную новость, берут из неё число и выбирают ветку действий. Отдельно — «новость по времени»:
  решения ЦБ и ФРС, операции Минфина (разбор правилами за 0,1 мс, плюс прямо с cbr.ru / federalreserve.gov).
- Облигации и НРД: статусы неисполнения (просрочка, техдефолт, дефолт), корпоративные события, дивиденды.
- Макростатистика США (BLS: нонфарм, CPI, PPI, JOLTS; BEA: ВВП, PCE), order flow MOEX (Russian Magellan), портфель T-Invest.

**Сделки** (выключены по умолчанию)
- Заявки в виджетах Т-Терминала и в стаканах CScalp (горячие клавиши, без API), голосовые заявки
  («купи пять лотов сбера по рынку»), стрелки ▲/▼ у шара для ручной корзины.

> ⚠️ **Про реальные деньги.** Исполнение работает, только когда пользователь сам включил его
> (Настройки → «Т-Терминал», там же лимиты лотов и рублей). Наблюдатели со сделками создаются выключенными.
> Программа распространяется «как есть», без гарантий, и не даёт инвестиционных рекомендаций.

Все функции можно включать и выключать на вкладке «Фичи».

## Установка

1. Скачайте `Nox-Setup-<версия>.exe` из [Releases](https://github.com/MrBeggins/nox/releases/latest).
2. Запустите. Права администратора не нужны. Установщик без цифровой подписи, поэтому Windows может показать
   «Система Windows защитила ваш компьютер» — «Подробнее» → «Выполнить в любом случае».
   Целостность файла можно сверить с `.sha256` рядом в релизе.
3. Мастер распакует программу в `C:\jarvis-lab` и `C:\jarvis-voice` (пути менять нельзя) и докачает:
   Python 3.11 и библиотеки (~1 ГБ), при необходимости Visual C++ Runtime и WebView2. По галочкам:
   Ollama + модель (~3 ГБ), Яндекс.Браузер, голос-клон Джарвиса (только NVIDIA). 10–30 минут в зависимости от интернета.
4. Запуск — ярлык **Nox**. При первом запуске откроется окно «Профиль»: имя и ключи (T-Invest, APIMIRA, BLS, BEA, FMP…).
   Ключи хранятся только у вас — `%APPDATA%\com.priler.jarvis\app.db`.
5. Ярлык **«Nox — окно Т-Терминала»**: один раз войдите в Т-Банк и откройте терминал с панелями новостей и календаря.

Обрыв интернета или ошибка — меню Пуск → **«Nox — починить установку»** (продолжит с места обрыва).
Журнал: `C:\jarvis-voice\install.log`. Удаление — «Параметры → Приложения → Nox».

**Требования:** Windows 10 1809+ / 11 x64, микрофон, ~6 ГБ на диске C: (с Ollama ~9 ГБ, с голосами-клонами ещё ~5–7 ГБ).
Видеокарта не обязательна.

## Как устроено

| Компонент | Порт | Назначение |
|---|---|---|
| `jarvis-app.exe` (Rust) | IPC ws **9712** | голосовой движок: Vosk → команды → мозг → голос |
| `jarvis-gui.exe` (Tauri 2 + Svelte 4) | — | окно: Пульс, Наблюдатели, Мозг, Память, Настройки, Фичи |
| `tts_silero_server.py` | **8123** | голос (Silero; или `tts_server.py` F5 / `tts_xtts_server.py` XTTS) |
| `invest_reader.py` | **8124** | T-Invest: портфель, котировки, заявки |
| `terminal_reader.py` | **8126** | главная служба: лента и календарь из Т-Терминала (CDP окна Яндекса :9222), роутер мозга, наблюдатели, CScalp, НРД, зрение |
| `magellan_reader.py` | **8127** | order flow MOEX |
| `bls_reader.py` / `bea_reader.py` | **8128** / **8129** | макростатистика США |
| `nox_watchdog.py` | **8130** | сторож: поднимает упавшие службы, гасит выключенные в «Фичах» |
| `sys_monitor.py` / `nox_notes.py` | **8132** / **8133** | монитор ПК, открытие программ / заметки и напоминания |
| Ollama | **11434** | локальный мозг и судья повторов |

Запуск всего — `C:\jarvis-lab\Jarvis.vbs` → `start-jarvis.ps1` (без консольных окон), дальше следит сторож.

## Сборка из исходников

Нужно: Rust (MSVC), Node.js LTS, Python 3.11, Visual Studio Build Tools (C++). Пути только ASCII.

```powershell
git clone https://github.com/MrBeggins/nox C:\nox
robocopy C:\nox\jarvis-lab   C:\jarvis-lab   /E
robocopy C:\nox\jarvis-voice C:\jarvis-voice /E
cd C:\jarvis-lab\frontend; npm install; npx vite build
cd C:\jarvis-lab; cargo build --release -p jarvis-app -p jarvis-gui; py -3.11 post_build.py
```

Модели (Vosk, GLiNER, эмбеддинги, Silero, RUAccent) в git не входят — проще всего поставить их установщиком.
Python-окружение: `release\installer\requirements-nox.txt` (torch — отдельно, CPU или CUDA 12.8).
Тесты: `C:\jarvis-voice\.venv\Scripts\python voice_tests\run_tests.py`, проверка служб — `voice_tests\health_check.py`.

**Сборка установщика** — папка [`release/`](release/): `build.py` собирает чистые исходники и нагрузку,
проверяет их на ключи и личные файлы и компилирует `Nox-Setup.exe` (Inno Setup 6).
