### 1.1 GLiNER (извлечение параметров из команд) — АКТИВИРОВАН
Поставлена модель **GLiNER Multi v2.1 int8** (~349 МБ) →
`C:\jarvis-lab\target\release\resources\models\gliner_multi-v2.1\` (`onnx/model.onnx`, `tokenizer.json`,
`gliner_config.json`, `model.toml`). В логе чисто: «GLiNER model loaded … slot extraction initialized».
Три грабли (все обойдены):
1. Загрузчик жёстко ищет `onnx/model.onnx` — int8-файл сохранять под этим именем.
2. Активация читается из db-ключа `slots_backend` (в `slots.rs`).
3. Правка `app.db` через PowerShell `Set-Content -Encoding UTF8` добавляет BOM → serde_json падает →
   ВСЕ настройки слетают в дефолт. Править `app.db` только в UTF-8 **без BOM**.

### 1.2 Переключатель движка слотов — СВЯЗАН С `slots_backend`
Раньше форма настроек писала `selected_slot_extraction_engine` + `selected_gliner_model`, а код читал

работает (применяется после перезапуска `jarvis-app`). Фронт+GUI пересобраны.

### 1.3 Модуль BLS — макростатистика США — ГОТОВ И РАБОТАЕТ
`C:\jarvis-voice\bls_reader.py`, порт **8128**. Источник: официальный `api.bls.gov` (бесплатно, без
Cloudflare). Показатели: нонфарм (CES0000000001, MoM в тыс), безработица (LNS14000000), часовая оплата
(CES0500000003), CPI (CUSR0000SA0 SA + CUUR0000SA0 NSA), базовый CPI (…L1E), PPI (WPSFD4/WPUFD4),
JOLTS (JTS…JOL). Два режима: **календарь** (заранее предупреждает голосом) + **факт** (зачитывает число).
- Расписание 2026 зашито (нонфарм/CPI/PPI 8:30 ET, JOLTS 10:00 ET) — только для предупреждений.
- Факт детектится по продвижению периода в API (само-корректируется, если дата сдвинется).
- Лимит без ключа ~25 запросов/сутки → все ряды одним батчем, опрос в основном в окне релиза.
- Эндпоинты: `/health /calendar /next /latest /value?q /mon?on /check`. Факт подаётся в сценарии.
- Проверено на живых данных: даты, ET→MSK (15:30/16:30 с учётом летнего времени), тексты, `/check`.

### 1.4 Модуль BEA — ВВП и PCE США — СОБРАН, ЖДЁТ КЛЮЧ
`C:\jarvis-voice\bea_reader.py`, порт **8129**. Источник: `https://apps.bea.gov/api/data`, набор NIPA.
- ВВП: таблица **T10101**, строка «Gross domestic product», freq=Q → DataValue = % изменение реального
  ВВП годовых (читается напрямую).
- PCE: таблица **T20804** (месячная): общий «Personal consumption expenditures» и базовый
  «PCE excluding food and energy». Из индекса считаю MoM и YoY. Строки матчатся по **LineDescription**
  (устойчиво к сдвигу номеров).
- **ОСОБЕННОСТЬ (просьба пользователя):** опрос API стартует **за 1 минуту до релиза** (окно T-1мин..T+40мин,
  в окне раз в ~10с; лимит BEA ~100/мин позволяет). Детект по `period:value` — ловит и новый период,
  и пересмотр оценки (вторая/третья оценка ВВП → «Уточнённая оценка…»).
- Расписание 2026 (8:30 ET): ВВП Q3 — 29.10 предв., 25.11 вторая, 23.12 третья; PCE — 29.10/25.11/23.12.
- Календарь/next работают БЕЗ ключа; `/latest`, `/value`, детект факта — требуют **UserID BEA**.
- Голос: ВВП/PCE → BEA; «календарь США»/«когда» объединяют BLS+BEA (`us_join` в `terminal.rs`).

## 4. Ключевые решения и ограничения

- **Без прогнозов/консенсуса.** BLS и BEA публикуют только факт и расписание. «Ожидалось X, вышло Y»
  потребовало бы стороннего календаря (investing/forexfactory) — упирается в Cloudflare/платно (пользователь
  выбрал факт+расписание).
- **ВВП — это BEA, не BLS** (разные источники; поэтому два модуля).
- **Лимиты API:** BLS ~25 запросов/сутки без ключа (батч + окно релиза); BEA ~100/мин (бан на час при
  превышении) — опрос за 1 мин до релиза раз в 10с.
- **Мозг сценариев** настраивается на пользователя: по умолчанию Ollama, можно Claude API или OpenAI API
  (ключи в `nox_scenarios.json`).
