# Установщик Nox («поставил и работает»)

Онлайн-установщик: ставит всё сам (Python, Ollama, ffmpeg, окружение, модели, настройки,
ярлык). Сам определяет видеокарту — на ПК с NVIDIA ставит голос **F5 (GPU)**, на ноутбуке
без видеокарты — лёгкий **Silero (CPU)**, чтобы озвучка была быстрой.

## Как пользоваться (на целевом ПК/ноуте)
1. Скопировать ВСЮ папку `nox-installer` на целевой компьютер (USB/облако).
2. Двойной клик по **`Установить-Nox.bat`** → согласиться на права администратора.
3. Дождаться окончания (качает ~2–4 ГБ: модели + мозг Ollama; нужен интернет).
4. Запуск — ярлык **«Nox»** на рабочем столе.

## Что сделает установщик
- winget: Python 3.11, Ollama, FFmpeg.
- Скопирует код в `C:\jarvis-lab` и `C:\jarvis-voice` (пути только ASCII — требование Vosk).
- Создаст `.venv` и поставит зависимости (torch CPU или CUDA 12.8 — по железу).
- Положит готовые `jarvis-app.exe` / `jarvis-gui.exe` (компилировать ничего не нужно).
- Модели: эмбеддинги и GLiNER — из комплекта (`models\`); Vosk — скачает; голос — F5 (GPU,
  качает) или Silero (CPU, скачается при первом запуске).
- Ollama: `qwen2.5:3b` + `OLLAMA_KEEP_ALIVE=-1`.
- Настройки `app.db` (мозг=Ollama, GLiNER вкл); ярлык на рабочем столе.

## Что нужно сделать один раз вручную (это нельзя автоматизировать)
- Войти в терминал T-Bank в открывшемся окне браузера (ваш логин).
- Вставить токен **T-Invest API** в настройках (вкладка Т-Терминал).
- Для ВВП/PCE — получить UserID на apps.bea.gov/api/signup и положить в `C:\jarvis-voice\bea_key.txt`.

## Состав папки установщика
```
nox-installer\
  Установить-Nox.bat        <- запускать это
  install.ps1               <- логика установки
  app.db.template           <- стартовые настройки (без токенов)
  jarvis-lab\               <- код (Rust+фронт)
  jarvis-voice\             <- код (Python-сервисы)
  bin\                      <- готовые jarvis-app.exe/jarvis-gui.exe + DLL
  models\                   <- эмбеддинги + GLiNER (неудобно качать онлайн)
```

> ⚠️ Установщик протестирован по шагам, но полный прогон на «чистом» ноутбуке ещё не делался —
> при первом запуске возможны правки. Лог установки: `%TEMP%\nox-install.log`.
