# Установка Nox

Самый простой путь — готовый установщик: **[Releases → Nox-Setup-&lt;версия&gt;.exe](https://github.com/MrBeggins/nox/releases/latest)**.
Он сам ставит Python, библиотеки, модели и создаёт ярлыки. Подробности — в разделе «Установка» в [README](README.md).

Сборка из исходников и сборка самого установщика — раздел «Сборка из исходников» в [README](README.md)
и [`release/README.md`](release/README.md).

Важно:
- пути установки фиксированы: `C:\jarvis-lab` и `C:\jarvis-voice` (кириллица в пути ломает распознавание речи);
- ключи и токены вводятся в окне «Профиль» и хранятся только локально (`%APPDATA%\com.priler.jarvis\app.db`) —
  не кладите их в git;
- исполнение заявок по умолчанию выключено (Настройки → «Т-Терминал»).
